# Security Policy

## Supported versions

TabletMidiPad is currently maintained on the latest release and the default branch. Older builds do not receive security updates.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting form:

https://github.com/tnware/TabletMidiPad/security/advisories/new

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

## Scope notes

TabletMidiPad interacts with Windows MIDI Services, Wacom Professional Service, and Wintab. Reports involving unsafe process launching, elevated execution, installer/uninstaller behavior, or failure to restore tablet controls are in scope.
